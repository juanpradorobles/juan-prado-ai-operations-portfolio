# WeDo controlled demo / Demo controlada de WeDo

## English

Interactive visual demo of WeDo for presentations. It uses fictional names, references, units, statuses, and amounts. It runs only in the browser and does not connect to WeDo, Supabase, email, payments, or other systems. Actions change the view only for the current session; reloading restores the sample.

The “AI-supported workflow” section illustrates a human-reviewed process concept. No AI model or automation is connected.

### View locally

Open `index.html` in a modern browser. English is the initial language; use the EN/ES control to switch. No dependencies, server, or keys are required.

### Future publication

This package can be served as a static site after reviewing the final content. It contains no SaaS source, credentials, environment variables, or Supabase data. Before publishing on HostGator, choose whether it will live at the domain root or under `/portal/` and align the routing rules.

## Español

Demo visual e interactiva de WeDo, preparada para presentaciones. Usa nombres, folios, unidades, estados y cantidades ficticios. Se ejecuta solo en el navegador y no se conecta a WeDo, Supabase, servicios de correo, pagos ni otros sistemas. Las acciones solo cambian la vista durante la sesión; al recargar se restablece el ejemplo.

La sección «Flujo asistido por IA» es una representación conceptual del proceso de revisión humana. No implica que un modelo de IA o una automatización estén conectados.

### Cómo verla

Abre `index.html` en un navegador moderno. El idioma inicial es inglés; usa el selector EN/ES para cambiar. No requiere dependencias, servidor ni claves.

### Publicación futura

Este paquete puede servirse como sitio estático después de revisar el contenido final. No contiene el código del SaaS, credenciales, variables de entorno ni datos de Supabase. Antes de publicarlo en HostGator hay que elegir si se alojará en el dominio raíz o bajo `/portal/` y alinear las reglas de rutas.
