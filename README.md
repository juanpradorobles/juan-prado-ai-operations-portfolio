# Juan José Prado Robles — AI Operations & Workflow Portfolio

## Español

Portafolio profesional bilingüe de Juan José Prado Robles, enfocado en operaciones y flujos de trabajo con inteligencia artificial. Presenta el proyecto WeDoPV, documentación y modelos de procesos operativos, sitios web bilingües y automatizaciones de apoyo para tareas y correo en funciones de CSR para HOA management, asistente virtual y asistente de gerencia.

### Herramientas de IA

- **Codex:** código, prototipos e iteración del producto.
- **Gemini:** investigación y exploración de información.
- **Claude:** revisión y auditoría de propuestas y materiales.
- **Pax:** agenda, coordinación y organización de tareas.

Las herramientas se coordinan según la tarea y los resultados se revisan antes de aplicarlos. Esta presentación describe un flujo de trabajo asistido por IA, no un producto autónomo ni experiencia como ingeniero de IA.

### WeDoPV y material de demostración

WeDoPV es un proyecto SaaS de administración de comunidades residenciales. El trabajo incluyó el diseño de flujos y asistentes de IA programados para apoyar operaciones HOA: revisión de correos, preparación de documentación y reportes, preguntas frecuentes y atención a clientes, seguimiento de cobros y facturas, tareas repetitivas y detección de duplicados. Los asistentes preparaban el trabajo para que el equipo lo editara y revisara antes de usarlo. Estas áreas describen el alcance trabajado; la implementación y validación de cada flujo debe confirmarse antes de presentarlo como una función activa. El portafolio usa mockups de demostración con información ficticia, no capturas de producción. El SaaS y sus configuraciones no forman parte de este repositorio.

Los materiales locales revisados contienen modelos de arquitectura y documentación operativa (roles, flujos, aprobaciones, comunicación y trazabilidad). No se encontraron muestras independientes y sanitizadas de SOP listas para publicación. Por eso el sitio describe esa experiencia, pero no afirma que el repositorio incluya ejemplos públicos de SOP. Para agregar muestras en una futura revisión se necesitarían SOP seleccionados por Juan y anonimizados para difusión.

### Ver localmente

Abre `index.html` en un navegador. El portafolio está en un solo HTML autocontenido; sus mockups SVG están integrados en el archivo. El idioma inicial es español y el selector ES/EN permite ver la versión inglesa.

### Publicar con GitHub Pages

1. Crea un repositorio público para el portafolio y sube únicamente los archivos revisados de este repositorio.
2. En GitHub, abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, elige la rama principal y la carpeta raíz `/`.
4. Guarda la configuración y usa la URL de GitHub Pages que GitHub genere.
5. Abre la URL publicada y revisa navegación, selector de idioma, enlaces de contacto y vista móvil antes de compartirla.

El repositorio contiene únicamente el portafolio y los archivos seleccionados para mostrar; no incluye el código fuente ni la configuración del SaaS WeDoPV.

### WeDoPV and demo material

WeDoPV is a SaaS project for residential community management. The work included designing scheduled AI assistants and workflows to support HOA operations: email review, document and report preparation, FAQs and customer support, collections and invoice follow-up, repetitive tasks, and duplicate detection. Assistants prepared work for the team to edit and review before use. These areas describe the scope explored; each workflow’s implementation and validation should be confirmed before presenting it as an active feature. The portfolio uses demonstration mockups with fictional information, not production screenshots. The SaaS and its configuration are not part of this repository.

The local materials reviewed contain architecture models and operational documentation (roles, workflows, approvals, communication, and traceability). No standalone, sanitized SOP samples ready for publication were found. The site therefore describes this experience without claiming that public SOP samples are included. Selected SOPs, approved by Juan and anonymized for public use, would be needed for a future addition.

### View locally

Open `index.html` in a browser. The portfolio is contained in one self-contained HTML file; its SVG mockups are embedded. Spanish is the default language, and the ES/EN selector switches to English.

### Publish with GitHub Pages

1. Create a public repository for the portfolio and upload only the reviewed files in this repository.
2. In GitHub, open **Settings → Pages**.
