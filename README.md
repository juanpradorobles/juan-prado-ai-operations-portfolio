# Juan José Prado Robles | AI Operations & Automation Portfolio

**AI operations, workflow design, and human-reviewed automation**

[Portfolio](https://juanpradorobles.github.io/juan-prado-ai-operations-portfolio/) · [WeDo demo](https://juanpradorobles.github.io/juan-prado-ai-operations-portfolio/demo-wedo/) · [Rebuilt Knowledge Center sample](https://juanpradorobles.github.io/juan-prado-ai-operations-portfolio/knowledge-center-sample/)

## English

This bilingual portfolio presents Juan José Prado Robles’s work applying AI to operational workflows across HOA customer service (CSR), virtual assistant, and assistant manager responsibilities. It highlights WeDo, a residential-community SaaS concept; SOP and operational documentation; bilingual web projects; and AI-assisted email and task workflows, prepared for human editing and review.

### Tool workflow
- **Codex:** code, prototypes, and product iteration.
- **Gemini:** research and information exploration.
- **Claude:** review and audit.
- **Pax:** scheduling and task organization.

Tools are coordinated by function, and outputs are reviewed before use. This describes AI-assisted work, not autonomous operations or AI engineering experience.

### WeDo and sample materials
The WeDo demo is a controlled portfolio mockup with fictional names, records, and figures. It illustrates selected product and workflow ideas; it is not the production SaaS, and this repository contains no SaaS source code or configuration. The demo does not imply every illustrated workflow is an active integration.

The Knowledge Center page is a newly written fictional sample. It demonstrates documentation structure and does not reproduce the original company Knowledge Center or any internal wording, procedures, templates, or information.

### View locally
Open index.html in a browser. The portfolio is a self-contained bilingual HTML page that opens in English. Selected demo and sample pages are in demo-wedo/ and knowledge-center-sample/.

### Publish with GitHub Pages
This repository is configured for GitHub Pages from the main branch and root folder. Commit changes to main, wait for the **pages build and deployment** workflow, then open the Pages link above and review the page and navigation.

## Español
Este portafolio bilingüe presenta el trabajo de Juan José Prado Robles aplicando IA a flujos operativos para funciones de CSR en HOA management, asistente virtual y asistente de gerencia. Incluye WeDo, un concepto SaaS para comunidades residenciales; diseño de SOP y documentación operativa; sitios web bilingües; y flujos de correo y tareas asistidos por IA, preparados para edición y revisión humana.

### Flujo de herramientas
- **Codex:** código, prototipos e iteración de producto.
- **Gemini:** investigación y exploración de información.
- **Claude:** revisión y auditoría.
- **Pax:** agenda y organización de tareas.

Coordino las herramientas por función y reviso sus resultados antes de usarlos. Esto describe un trabajo asistido por IA, no operaciones autónomas ni experiencia como ingeniero de IA.

### WeDo y materiales de muestra
El demo de WeDo es un mockup controlado con nombres, registros y valores ficticios. Ilustra algunas ideas de producto y flujos; no es el SaaS de producción, y este repositorio no contiene su código fuente ni configuración. El demo no implica que cada flujo ilustrado sea una integración activa.

La página Knowledge Center es una muestra ficticia redactada desde cero. Demuestra estructura documental y no reproduce el Knowledge Center original de la empresa ni información interna.

### Ver localmente
Abre index.html en un navegador. El portafolio es una página HTML bilingüe autocontenida que inicia en inglés. Las páginas de muestra están en demo-wedo/ y knowledge-center-sample/.

### Publicar con GitHub Pages
Este repositorio está configurado para GitHub Pages desde la rama main y la carpeta raíz. Confirma los cambios en main, espera a que termine el flujo **pages build and deployment** y abre el enlace de Pages para revisar la página y su navegación.
